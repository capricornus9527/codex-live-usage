# Codex Live Usage

A Windows companion that shows one Codex++-style token usage badge below the
latest Codex Desktop assistant response.

> Unofficial community project. Not affiliated with or endorsed by OpenAI.

## Planned features

- Transparent, click-through overlay outside the badge.
- Original Codex++ badge styling: teal border, subtle teal background, 7 px
  radius, 12 px single-line text.
- Context used/limit, cache hit rate, input/output tokens, output speed, and
  session total read from local rollout JSONL.
- Automatic startup at Windows login and automatic Codex window following.
- No network requests, API keys, CDP, DOM injection, or Codex file changes.

## Status

Implementation is in progress. Windows 10/11 x64 and .NET 9 are required.
